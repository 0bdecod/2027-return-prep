# 11/04 — 세 정수의 최댓값

정수 `a`, `b`, `c`의 최댓값을 세 가지 방법으로 구한다.
모두 입력이 세 개로 고정되어 시간·추가 공간 복잡도는 O(1)이다.
입력이 n개라면 순차 비교 방식은 O(n) 시간이 필요하다.

## 1. 독립 조건문

```c
int max = a;
if (max < b) {
    max = b;
}
if (max < c) {
    max = c;
}
```

현재 최댓값을 갱신한다. 두 번째 비교는 첫 번째 비교 결과를 사용하므로
두 if를 else if로 연결하면 안 된다.

## 2. 명시적인 분기

```c
int max;
if (a >= b && a >= c) {
    max = a;
} else if (b >= a && b >= c) {
    max = b;
} else {
    max = c;
}
```

동일한 최댓값이 여러 개 있어도 해당 값을 반환한다.

## 3. 삼항 연산자

```c
int max = (a > b) ? a : b;
max = (max > c) ? max : c;
```
