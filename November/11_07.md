## 변수 주소가 실행마다 달라질 수 있는 이유

ASLR(Address Space Layout Randomization)은 스택, 힙, 라이브러리 등
메모리 영역의 배치를 무작위화하는 보안 기법이다.
실제 적용 영역과 주소 변화는 운영체제, 빌드 설정, 실행 환경에 따라 달라진다.
따라서 주소가 매번 반드시 바뀐다고 단정하거나, 주소 출력만으로 ASLR 적용 여부를 확정할 수는 없다.

```c
int value = 10;
int *pointer = &value;
printf("%p\n", (void *)pointer);
```

이 코드는 `<stdio.h>`가 필요하다. `&value`는 주소를 얻고,
`*pointer`는 가리키는 객체의 값을 읽거나 변경한다.
`%p`에 전달하는 객체 포인터는 `void *`로 변환한다.

## 길이 5인 배열의 범위

```c
int array[5] = {1, 2, 3, 4, 5};
```

유효한 원소는 `array[0]`부터 `array[4]`까지다.
`array[5]`를 읽거나 쓰는 것은 정의되지 않은 동작(Undefined Behavior)이다.
오류 메시지나 충돌이 반드시 발생하는 것은 아니다.

`array + 5`처럼 마지막 원소 바로 다음을 가리키는 포인터를 만드는 것은 허용되지만,
그 포인터를 역참조해서는 안 된다.
