주제: 포인터와 부분 배열을 활용한 함수 재사용

표현식	의미
arr	첫 번째 원소의 주소
arr + 2	세 번째 원소의 주소
*(arr + 2)	세 번째 원소의 값
&arr[2]	세 번째 원소의 주소
arr[2]	세 번째 원소의 값

const int *arr가 함수에 선언되었을 때 main 함수에서는 함수를 불러올 때 '함수이름(arr, ...)'로 하면 된다.

코드: array.c 참고

About security:
Out of Bounds Read(범위 밖 메모리 읽기)

오늘 작성한 코드를 적용해서
sum_array(arr + 2, 5);를 선언하게 되면
실제로 읽을 수 있는 원소는 3개이지만 5개를 읽도록 선언했다.
C의 포인터에는 일반적으로 배열의 전체 길이 정보가 포함되어 있지 않으므로 함수는 이를 자동으로 판단하지 못한다.
고의적인 메모리에 대한 악의적 접근은 프로그램 충돌 및 메모리 정보 노출로 이어짐
