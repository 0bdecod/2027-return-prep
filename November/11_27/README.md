# 2026.11.27 - fgets와 문자열 개행 제거

## 1. 학습 목표

- fgets를 활용한 안전한 문자열 입력
- 문자열 길이와 배열 크기의 차이 이해
- 개행 문자 및 널 문자 처리
- 경계값 검사와 입력 검증

## 2. 핵심 개념

### fgets()

- **용도:** 표준 입력 또는 파일에서 지정된 크기 이내의 문자열을 읽어오는 함수이다.
- **매개변수:** `fgets(name, sizeof(name), stdin)`을 기준으로 첫 번째는 문자열을 저장할 배열, 두 번째는 입력 버퍼의 크기, 세 번째는 입력 스트림을 의미한다.
- **반환값:** 입력에 성공하면 문자열을 저장한 배열의 시작 주소를 반환하고, 읽기 오류가 발생하거나 아무 문자도 읽기 전에 EOF에 도달하면 NULL을 반환한다.
- **주의사항:** 최대 배열 크기에서 1을 뺀 만큼의 문자를 읽으며, 성공적으로 읽은 문자열의 끝에는 널 문자(`\0`)가 저장된다. 입력 공간이 충분하면 개행 문자(`\n`)도 함께 저장된다. 배열 크기를 초과하는 입력은 입력 스트림에 남을 수 있다.

### strlen()과 sizeof()

- **strlen():** 문자열의 시작부터 최초의 널 문자(`\0`) 이전까지의 바이트 수를 반환하는 함수이다. `<string.h>` 헤더 파일이 필요하다.
- **sizeof():** 변수 또는 자료형이 차지하는 메모리 크기를 바이트 단위로 반환하는 연산자이다.
- **두 연산의 차이:** strlen은 현재 저장된 문자열의 길이를 반환하지만, sizeof는 배열 자체가 차지하는 메모리 크기를 반환한다. 따라서 문자열의 내용이나 길이가 변경되어도 배열 자체의 sizeof 값은 변하지 않는다. 단, 배열을 함수의 포인터 매개변수로 전달하면 sizeof로 원래 배열의 크기를 구할 수 없다.

### 개행 문자 제거 원리

- **개행 문자(`\n`):** 줄바꿈을 나타내는 문자이다. fgets 사용 시 입력 공간이 충분하면 Enter 입력에 해당하는 개행 문자도 배열에 저장된다.
- **널 문자(`\0`):** C언어에서 문자열의 끝을 나타내는 문자이다. strlen은 널 문자를 길이에 포함하지 않는다.
- **개행 제거 방법:** 문자열 내부에 개행 문자가 존재하는지 확인한 후, 해당 위치의 값을 널 문자로 변경한다. 이 과정에서 배열의 크기는 변하지 않지만 논리적인 문자열의 길이는 감소한다.

## 3. 실습 결과

실습 환경: `char name[8] = {0};`

각 입력은 프로그램을 독립적으로 실행하고 Enter를 누르는 상황을 기준으로 한다.

| 입력 | 제거 전 길이 | 제거 후 길이 | 특이사항 |
|---|---:|---:|---|
| A | 2 | 1 | 개행 문자 제거 |
| 빈 줄 | 1 | 0 | 개행 문자만 저장됨 |
| ABCDEF | 7 | 6 | 개행 문자까지 저장 가능 |
| ABCDEFG | 7 | 7 | 개행 문자가 입력 스트림에 남음 |
| ABCDEFGHIJ | 7 | 7 | HIJ와 개행 문자가 입력 스트림에 남음 |

- 배열의 전체 크기는 8바이트이다.
- 널 문자를 제외하고 최대 7바이트까지 입력받을 수 있다.
- 개행 문자가 저장되지 않은 경우에는 문자열 길이가 감소하지 않는다.
- 입력 성공 여부와 전체 입력을 정상적으로 읽었는지 여부는 별도로 판단해야 한다.

## 4. 메모리 관찰

입력값이 ABCDEF인 경우를 기준으로 관찰하였다.

**개행 제거 전**

| 인덱스 | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|---|---|---|---|---|---|---|---|---|
| 저장값 | A | B | C | D | E | F | \n | \0 |

**개행 제거 후**

| 인덱스 | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|---|---|---|---|---|---|---|---|---|
| 저장값 | A | B | C | D | E | F | \0 | \0 |

- **개행 제거 전 널 문자 위치:** 인덱스 7
- **개행 제거 후 최초의 널 문자 위치:** 인덱스 6
- **배열 크기의 변화 여부:** 개행 제거 전후 모두 8바이트로 동일하다.

개행 문자를 널 문자로 변경하면 문자열의 종료 위치가 앞당겨진다. 실제 메모리 공간을 제거하거나 배열의 크기를 줄이는 것은 아니다.

## 5. 보안 관점

- **관찰:** 배열의 크기를 초과하는 문자열을 입력하더라도 fgets에 올바른 버퍼 크기를 전달하면 배열의 범위를 벗어나 데이터를 저장하지 않는다. 다만 초과 입력은 입력 스트림에 남을 수 있다.
- **원인:** fgets는 지정된 크기에서 1을 뺀 만큼의 문자만 읽고 문자열의 마지막에 널 문자를 저장하기 때문이다.
- **수정 또는 판단:** fgets의 반환값을 검사하여 입력 성공 여부를 확인하고, 입력된 문자열에 개행 문자가 존재하는 경우에만 제거해야 한다. 개행 문자가 존재하지 않는 경우에는 입력이 버퍼 크기에 도달했거나 개행 없이 EOF에 도달했을 가능성을 고려해야 한다.
- **재확인:** 빈 줄, 일반 문자열, 최대 저장 가능 길이의 문자열, 배열 크기를 초과하는 문자열을 각각 입력하여 경계값에서의 동작을 확인한다.

안전한 문자열 입력 함수를 사용하는 것만으로 모든 입력 관련 문제가 해결되는 것은 아니다. 입력 길이와 반환값을 검증하고, 배열의 경계를 고려하는 습관이 필요하다.

## 6. 학습 소감

- **새롭게 이해한 내용:** 문자열의 논리적인 길이와 실제 할당된 메모리 크기는 서로 다른 개념이며, 널 문자의 위치에 따라 문자열의 길이가 결정된다는 점을 이해하였다.
- **어려웠던 부분:** 입력 길이가 배열의 최대 저장 가능 길이에 도달했을 때 개행 문자가 배열에 저장되지 않는 이유와, 입력 스트림에 데이터가 남는 원리를 이해하는 부분이 어려웠다.
- **추가로 학습할 내용:**
  - strchr()과 strcspn()을 활용한 개행 문자 제거
  - getchar()를 활용한 초과 입력 처리
  - EOF와 NULL의 차이
  - 입력 버퍼 및 표준 입력 스트림의 동작 원리
  - 버퍼 오버플로우의 발생 원리와 방지 방법
