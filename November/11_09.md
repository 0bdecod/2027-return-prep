# 11/09 — 함수와 값 전달

함수로 기능을 분리하면 수정과 재사용이 쉬워진다.
C의 인수 전달은 항상 값에 의한 전달(Call by Value)이다.

## 정수 값을 전달하기

```c
void change_value(int x) {
    x = 100;
    (void)x;
}
```

매개변수에는 인수의 값이 복사된다. 함수 안에서 x를 변경해도 호출자의 변수는 바뀌지 않는다.
`(void)x;`는 예제에서 변경된 지역 값을 사용하지 않는다는 의도를 명시한다.

## 포인터 값으로 원본 변경하기

```c
void change_pointer(int *x) {
    *x = 100;
}
```

`change_pointer(&a)`를 호출하면 a의 주소가 포인터 매개변수에 복사된다.
`*x`를 통해 a를 변경할 수 있다. 이를 C++의 참조 전달과 구별해야 한다.
주소도 값으로 복사되므로, 함수가 포인터 매개변수 자체를 다른 주소로 바꾸어도
호출자의 포인터 변수는 바뀌지 않는다.

이 함수에는 유효하고 쓰기 가능한 int 객체의 주소를 전달해야 한다.
NULL, 수명이 끝난 객체의 주소, 초기화되지 않은 포인터를 전달하면 안 된다.

## swap

```c
void swap(int *a, int *b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}
```

호출은 `swap(&a, &b)`처럼 한다.
`swap(a, b)`는 int 값을 전달하므로 int 포인터를 받는 함수의 인수 형식에 맞지 않는다.
두 인수 모두 유효하고 쓰기 가능한 int 객체의 주소여야 한다.
같은 객체의 주소를 두 번 전달하면 값은 그대로 유지된다.
